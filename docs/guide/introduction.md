FEI-UI-DESIGN 是一个基于 Vue 3 的组件库，提供 59 个开箱即用的组件，覆盖通用、布局、数据录入、数据展示、导航与反馈等场景。

要了解如何安装，参见 [安装](/guide/installation)。

它由 [f-ui-one](https://ymf930.gitee.io/f-ui-one/#/guide) 演进而来，可以平滑地过渡和切换。

## 最新版本

[![NPM version](https://img.shields.io/npm/v/fei-ui-design.svg)](https://www.npmjs.com/package/fei-ui-design)

## 组件丰富

我们提供了 59 个组件，基本可以满足日常开发需求。所有组件均支持 tree shaking。

## 使用 TypeScript 编写

使用 TypeScript 进行了重构，提供完整的类型推导。另外，你不需要导入任何 CSS 就能让组件正常工作。

## 主题样式

使用 PostCSS 重构了样式，增加了更多的主题颜色配置。我们提供了一个使用 TypeScript 构建的类型安全主题系统，你只需要按需配置并导出一个覆盖对象即可。
